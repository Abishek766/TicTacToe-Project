# Tic Tac Toe using Object-Oriented Programming (OOP) in Java

This project implements the classic Tic Tac Toe game using core OOP principles such as inheritance, abstraction, and polymorphism in Java.

## 🎮 Features
- Two game modes:
  - Human vs. Human
  - Human vs. AI
- AI player uses basic decision logic (e.g., Minimax can be added)
- Clean modular design using classes

## 🧱 Object-Oriented Structure
- `Player` (Abstract base class)
  - Contains common attributes: name, symbol
  - Defines `makeMove()` method
- `HumanPlayer` (Inherits Player)
  - Handles user input
- `AIPlayer` (Inherits Player)
  - Contains logic to choose best move

## 🛠 Technologies
- Java
- OOP Concepts: Inheritance, Abstraction, Encapsulation, Polymorphism

## 🎯 Learning Objectives
- Reinforce OOP principles in a practical way
- Work with game loops and user input
- Implement decision logic for AI players
